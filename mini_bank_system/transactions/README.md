# Mini Bank Management System

A secure and fully functional backend API for a banking management system built using **Python, Django, Django REST Framework (DRF), and SimpleJWT**.

---

## Features

* **User Authentication & Authorization:** Secure registration, login, token obtain, and token refresh using JWT.
* **Account Management:** User account creation and profile management.
* **Transactions:** Secure endpoints for depositing money, withdrawing money, and viewing transaction history.
* **Admin Panel:** Full integration with Django Admin to view and manage users, accounts, and transactions.

---

## Tech Stack

* **Language:** Python
* **Framework:** Django, Django REST Framework (DRF)
* **Authentication:** djangorestframework-simplejwt
* **Database:** SQLite (Default)
